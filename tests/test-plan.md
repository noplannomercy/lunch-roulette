## Affected Pages/Routes
- `index.html#roulette` — 룰렛 휠, 돌리기 버튼, 메뉴 관리 accordion
- `index.html#vote` — 투표 리스트, +1 버튼, 바 차트, "투표 결과로 룰렛 돌리기"
- `index.html#history` — 히스토리 리스트, 빈 상태

## Key Interactions to Verify
- 메뉴 추가 (정상, 빈값, 공백, 중복, 긴 이름) on 룰렛 탭
- 메뉴 삭제 on 룰렛 탭
- 돌리기 버튼 클릭 → 3초 애니메이션 → 결과 오버레이 on 룰렛 탭
- 투표 +1 → 바 차트 업데이트 on 투표 탭
- "투표 결과로 룰렛 돌리기" → 탭 전환 + 스핀 on 투표 탭
- 결과 확인 → 히스토리 기록 + 투표 초기화 on 오버레이
- 탭 전환 (3개 탭) + URL hash 유지

## Edge Cases
- 메뉴 0개 상태: 돌리기 disabled + "메뉴를 추가해주세요"
- 메뉴 1개 상태: 돌리기 disabled + "더 추가하면 재밌어요!"
- 메뉴 전체 삭제 후 돌리기 버튼 상태
- 회전 중 돌리기 버튼 재클릭 (무시되어야 함)
- 같은 날 룰렛 두 번 돌리기 (둘 다 히스토리에 기록)
- 새로고침 후 데이터 유지 (localStorage)
- 모바일 뷰포트 (375px) 레이아웃

## Critical Paths
- 메뉴 등록 → 투표 → 가중치 룰렛 → 결과 확인 → 히스토리 기록 (end-to-end)
- 빈 상태에서 시작 → 메뉴 추가 → 첫 스핀 (first-use flow)
